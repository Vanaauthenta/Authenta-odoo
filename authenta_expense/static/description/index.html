Authenta Receipt Verification

Catch fake and edited expense receipts before they are approved

Every receipt attached to an expense is checked by the Authenta service in the background. Expense reports with a receipt Authenta flags as fake, or that could not be verified, cannot be approved until they are resolved. Employees keep using Odoo Expenses exactly as before.

How it works

  1. An employee creates an expense and attaches the receipt (JPEG, PNG or PDF) as usual.
  2. Odoo sends the receipt to Authenta in the background; nothing changes for the employee.
  3. The expense shows the result: Verified, Fake Receipt or Not Verified.
  4. Managers cannot approve a report while one of its receipts is fake, still being verified or could not be verified. Refusing a report is always possible.

Setup in one click

  1. Install the module (it depends only on Expenses).
  2. Go to Expenses → Configuration → Settings → Authenta Receipt Verification (administrators only) and click Connect.
  3. Log in to Authenta as an owner or admin of your organization and click Authorize. You are sent back to Odoo, which shows Connected. No API key is copied.
  4. Tick Verify receipts with Authenta and save.

If Connect cannot be used, an integration API key created in Authenta can be entered manually under the Connect button (Save & Test). Disconnect revokes the credential.

Requirements and data

  • An active Authenta account. Verification usage is billed by Authenta to your Authenta organization; the module itself is free.
  • Odoo must be reachable by administrators over https (http is accepted on localhost only), because Authenta sends the browser back to Odoo after authorization.
  • While verification is enabled and Odoo is connected, each receipt attached to an expense (the file, its file name, and technical references to the expense and the attachment) is sent to Authenta to check that it is authentic. The result is stored on the expense in Odoo.
  • Only administrators can connect, test or disconnect Authenta; employees never see credentials.
